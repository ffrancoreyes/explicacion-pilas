Pilas - Stacks (LIFO: Last In, First Out)

Significado de cada puntero, color y regla de parcial en los dibujos
pila = xxx3 ───►

Puntero a la Cima (Tope): apunta siempre al último nodo que ingresó (arriba de todo). Tanto push() como pop() operan por este único extremo.

aux = xxx3 ───►

Puntero auxiliar celeste: en pop() toma la dirección de la cima (aux = pila;) para poder avanzar pila = aux->sgte; y liberar con delete aux;.

int retorno

Dato rescatado: guarda aux->info antes de hacer delete aux;. Si hacés otro pop() sin pasarlo a una pila auxiliar, lo pisás.

*sgte ───►

Enlace hacia abajo: cada nuevo nodo se conecta al que estaba antes en la cima mediante nuevo_nodo->sgte = pila;. El primero que entró apunta a NULL.

¡NO SE RECORREN!

Regla de Parcial: jamás digas "recorrer una pila". Para ver sus elementos sin perderlos, sacalos con pop(pila) y guardalos con push(pilaAux, dato).

Resumen del Apunte: 06 - Pilas - Stacks (LIFO)

Push / apilar / insertarPila

  1. Crear el nodo y asignar el dato:
    Nodo *nuevo_nodo = new Nodo();
    nuevo_nodo->info = info;
  2. Conectar al *sgte a través del puntero pila:
    nuevo_nodo->sgte = pila;
  3. Mover el puntero pila al inicio de todo (nueva cima):
    pila = nuevo_nodo;

Pop / desapilar / quitarPila

  1. Crear un puntero aux que tome la dirección de la pila:
    Nodo *aux = pila;
  2. Rescatar el dato para luego retornarlo:
    int retorno = aux->info;
  3. Mover el puntero pila al *sgte:
    pila = aux->sgte;
  4. Liberar la memoria con aux y retornar el valor guardado:
    delete aux; return retorno;
Consejos clave para el Parcial:
  • Las pilas NO se recorren (está prohibido decir que "recorrés una pila").
  • Para mostrar o buscar elementos sin perderlos, se desapilan con retorno = pop(pila) y se van guardando en una pilaAux con push(pilaAux, retorno).
struct Nodo{
    int info;
    Nodo *sgte;
};

void push(Nodo *&pila, int info){
    Nodo *nuevo_nodo = new Nodo();
    nuevo_nodo->info = info;
    nuevo_nodo->sgte = pila;
    pila = nuevo_nodo;
}

int pop(Nodo *&pila){
    Nodo *aux = pila;
    int retorno = aux->info;
    pila = aux->sgte;
    delete aux;
    return retorno;
}
