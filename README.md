# Explicacion de Pilas (Stacks) en C++

Una herramienta visual e interactiva para entender y practicar cómo funcionan las Pilas (estructura LIFO: Last In, First Out) en C++. 

## ✨ ¿Qué incluye?

* **Pizarra Interactiva:** Visualiza las operaciones `push()` y `pop()` en tiempo real.
* **Explicación Paso a Paso:** Entiende cómo se mueven los punteros (`pila`, `aux`, `*sgte`) en la memoria.
* **Código en Vivo:** Genera automáticamente el código C++ del `main()` a medida que interactúas con la pizarra.
